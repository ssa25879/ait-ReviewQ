## 3. day4-home-queue 핵심 결정 (상세는 `openspec/changes/day4-home-queue/design.md`)

- **경로 변경 (BREAKING)**: 홈 `#/`, 과목·덱 목록 `#/subjects`, 전체 덱 세션 `studyAll` `#/study`. 덱 세션 `#/deck/{id}/study`는 유지.
  - seed: subjects→[home], deck→[home, subjects], card·study→[home, subjects, deck], studyAll→[home]
  - 알 수 없는 해시·없는 대상 → home
- **오늘 날짜**: `app/today.tsx`의 `TodayProvider`/`useToday()`가 관리. `visibilitychange`(visible) 때 다시 계산. 세션 화면은 마운트 때 `todayLocal()`을 직접 써서 날짜 고정(기존 유지).
- **시계 되돌림**: `domain/clock.ts` `checkClock(lastOpenedDate, today)`. 되돌림이면 `lastOpenedDate`를 유지하고 홈에 경고. 아니면 `bq:meta`에 바로 저장(`saveLastOpenedDate`, saveQueue를 거치지 않음).
- **홈**: 오늘 복습 수(cards+overflow), 연체 수(0이면 숨김), 상한 안내, 시계 경고, 과목별 행(누르면 목록). 하단은 [과목·덱 관리(보조) | 학습 시작(주)], 카드 0장이면 첫 사용 안내 + "과목·덱 만들기". 대화상자 금지.
- **StudySession 일반화**: `deckId` 선택 값. 전체 덱이면 제목 "오늘 복습", 돌아가기 "홈으로". 시작 시 overflow를 고정해 완료 화면에 안내.
- **상한 문구 하나로 통일**: `overflowNotice(n)` = "오늘은 100장까지 학습해요. 나머지 N장은 내일 이어서 나와요."
- **시계 경고 문구**: "기기 날짜가 마지막으로 앱을 연 날(M월 D일)보다 이전이에요. 날짜 설정을 확인해 주세요."

### 주의할 점
- 기존 CDP 스크립트 3개(`crud`·`review`·`study`)는 `#/`를 과목·덱 목록으로 가정한다. tasks 5.1에서 진입 주소를 `#/subjects`로 바꾸고 목록 복귀 기대를 고쳐야 한다(바꾼 줄은 보고에 적기).
- `SubjectList`·`DeckDetail` 등에서 `navigate({ name: 'subjects' })`, `replace({ name: 'subjects' })` 호출처를 점검(tasks 1.1).
- `DeckDetail`의 `todayLocal()`를 `useToday()`로 교체(tasks 2.3).

## 4. day4-stats (P1) 핵심 결정 (상세는 `openspec/changes/day4-stats/design.md`)

- 경로 `#/stats`, seed [home]. 홈 본문에 "통계" 행 추가(하단 버튼은 그대로).
- capability는 새 `stats-screen` 하나. 홈의 통계 진입도 이 spec에 넣어, 아직 아카이브되지 않은 `home-screen`에 의존하지 않게 했다.
- 표시 항목(기획서 F9, 5.2):
  - 오늘 완료 수 = 오늘 날짜 판정 로그 수(첫 판정만 로그에 남음)
  - 전체 카드 수
  - 단계별 분포: stage 0(새 카드·다시 학습), 1~6(간격 1·3·7·14·30·60일)별 카드 수
  - 최근 7일 학습 수: 오늘 포함 7일의 날짜별 로그 수. 로그는 이번 달·지난달만 로드되지만 7일 범위는 항상 그 안에 든다.
- 그래프 라이브러리 없이 숫자 + CSS 막대(기획서 "지연 시 그래프 제외, 숫자 요약만").
- 계산은 `domain/stats.ts` 순수 함수(`todayDoneCount`·`stageDistribution`·`recentDailyCounts`)로 두고 단위 테스트(F9 완료 조건: 로그 기반 수치가 수동 계산과 일치).
- `useToday()`(home-queue에서 생성)에 의존하므로 home-queue 아카이브 뒤에 진행.

## 5. 검증 환경 메모

- 헤드리스 Edge: `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
- Bash 샌드박스에서는 Edge CDP 연결이 실패한다 → **PowerShell에서 `node` 실행**, 출력 폴더는 **절대 경로**(상대 경로면 Edge가 exit 21로 종료).

  ```
  node study.mjs "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" "<절대경로>\out-study"
  ```
- 테스트 도우미 `__app()`은 React fiber의 이전(alternate) 트리를 읽을 수 있다. 판정 로그 수는 저장소(`__ls('bq:logs:YYYY-MM')`)로 센다.
