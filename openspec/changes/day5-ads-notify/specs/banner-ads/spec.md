# Spec Delta

## Purpose

배너 광고를 어떤 조건에서 어느 화면에 몇 개 보여 주는지, 개발·테스트에서 어떤 광고 ID를 쓰는지, 광고를 보여 줄 수 없을 때 화면이 어떻게 남는지 정의한다.

## ADDED Requirements

### Requirement: 광고 기능 플래그
광고 기능 플래그가 꺼져 있으면 시스템은 어떤 화면에도 광고 영역을 그리지 않고 광고 SDK를 호출하지 않아야 한다(MUST NOT). 플래그의 기본값은 꺼짐이다.

#### Scenario: 기본 빌드
- **WHEN** 광고 플래그를 지정하지 않은 빌드로 과목·덱 목록과 학습 완료 화면을 연다
- **THEN** 두 화면 모두 광고 영역이 없고 광고 SDK 초기화·배너 부착 호출이 일어나지 않는다

### Requirement: 테스트 광고 ID
운영 광고 그룹 ID가 빌드에 주입되지 않았으면 시스템은 테스트 광고 ID(`ait-ad-test-banner-id`)로 배너를 요청해야 한다(SHALL). 운영 광고 그룹 ID는 저장소에 포함되어서는 안 된다(MUST NOT).

#### Scenario: 개발 빌드
- **WHEN** 광고 플래그를 켜고 운영 ID 없이 과목·덱 목록을 연다
- **THEN** 배너 요청의 광고 그룹 ID가 `ait-ad-test-banner-id`다

### Requirement: 광고 배치
광고 플래그가 켜져 있으면 시스템은 과목·덱 목록의 스크롤 영역 하단과 학습 완료 화면의 결과 요약 아래에만 배너를 1개씩 두어야 한다(SHALL). 홈, 학습 세션 진행 중, 카드 작성·편집, 통계, 복구 화면에는 광고를 두어서는 안 된다(MUST NOT). 배너는 버튼과 붙어 있지 않도록 위아래로 24px 이상 떨어뜨리고, 하단 고정 버튼이나 다른 요소와 겹치지 않는다.

#### Scenario: 화면당 1개
- **WHEN** 광고 플래그를 켠 빌드로 과목·덱 목록을 연다
- **THEN** 광고 영역이 정확히 1개이고 하단 고정 버튼과 겹치지 않는다

#### Scenario: 학습 중 광고 없음
- **WHEN** 광고 플래그를 켠 빌드로 학습 세션의 카드 판정 화면을 연다
- **THEN** 광고 영역이 없다

### Requirement: 광고를 보여 줄 수 없을 때
기기가 배너 광고를 지원하지 않으면 시스템은 광고 영역을 그리지 않아야 한다(SHALL). 광고가 없거나(No fill) 렌더에 실패하면 광고 영역을 접어 빈 공간을 남기지 않아야 한다(SHALL). 어느 경우에도 화면의 다른 내용과 뒤로가기는 그대로 동작한다.

#### Scenario: 미지원 기기
- **WHEN** 배너 광고 지원 여부가 false인 환경에서 과목·덱 목록을 연다
- **THEN** 광고 영역과 빈 공간 없이 목록이 보인다

#### Scenario: 광고 없음
- **WHEN** 배너 요청 결과가 광고 없음이다
- **THEN** 광고 영역이 사라지고 목록 아래에 빈 공간이 남지 않는다

### Requirement: 광고 영역 수명주기
시스템은 광고 SDK를 앱 실행 중 한 번만 초기화해야 하며(SHALL), 광고가 있는 화면을 떠나면 그 배너를 해제해야 한다(SHALL). 타이머 등으로 배너를 다시 부착하거나 새로 고쳐서는 안 된다(MUST NOT).

#### Scenario: 화면 왕복
- **WHEN** 광고 플래그를 켠 빌드에서 과목·덱 목록 → 덱 상세 → 과목·덱 목록으로 이동한다
- **THEN** SDK 초기화는 1번이고, 처음 배너는 덱 상세로 갈 때 해제되며 목록으로 돌아오면 배너가 1개만 다시 부착된다
