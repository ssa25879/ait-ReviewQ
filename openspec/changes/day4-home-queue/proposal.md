# Proposal

## Why

지금은 앱을 열면 과목·덱 목록이 나오고, 학습은 덱마다 따로 시작해야 한다. 기획서의 핵심 흐름("앱 진입 → 홈(오늘 복습) → 학습 세션 → 완료 → 홈")과 F7(오늘 복습 목록: 홈 숫자와 세션 카드 수 일치)이 아직 없다. 날짜 규칙(포그라운드 복귀 시 오늘 재계산, 기기 시계 되돌림 경고)도 기획서 6.3·6.4에 [가정]으로만 있다. Day 4 완료 조건("날짜 경계·연체 시나리오가 기대 결과와 같다")을 채우려면 이 부분을 화면과 규칙으로 고정해야 한다.

## What Changes

- **홈 화면을 새 최초 화면으로 둔다(`#/`).** 오늘 복습 수, 그중 연체 수, "학습 시작" 버튼, 과목별 오늘 복습 수 요약, "과목·덱 관리" 진입을 보여 준다. 카드가 하나도 없으면 첫 사용 안내를, 오늘 복습이 0장이면 그 안내를 보여 준다.
- **BREAKING(경로)**: 과목·덱 목록 경로를 `#/`에서 `#/subjects`로 옮긴다. 하위 화면에 바로 들어오면 홈부터 상위 화면을 채운다. 없는 덱·카드 주소와 알 수 없는 주소는 홈으로 바꾼다.
- **전체 덱 학습 세션(`#/study`)**: 홈의 "학습 시작"으로 열리고, 덱 세션과 같은 화면 규칙(뒤집기·판정·연타 방지·완료·뒤로가기 확인)을 따른다. 완료 화면에서는 홈으로 돌아간다.
- **하루 상한 초과 안내**: 오늘 복습 대상이 100장을 넘으면 홈·덱 상세·학습 완료 화면에서 "나머지 N장은 내일 이어서 나와요"를 알린다. 덱 상세의 "오늘 복습 N장"과 세션 전체 수가 어긋나 보이던 문제(day3 리뷰 지적)를 안내로 해소한다.
- **포그라운드 복귀 시 오늘 날짜 재계산**: 앱이 다시 보이면 오늘 날짜를 다시 구해 홈·덱 상세의 숫자를 갱신한다. 진행 중인 세션의 날짜는 바꾸지 않는다(기존 세션 날짜 고정 유지).
- **기기 시계 되돌림 경고**: 오늘이 마지막으로 앱을 연 날보다 이전이면 홈에 경고를 보이고, 마지막으로 연 날을 갱신하지 않는다. 정상일 때는 마지막으로 연 날을 오늘로 갱신해 저장한다.

범위 밖: 통계 화면(F9, 별도 change `day4-stats`), 설정 화면, 추가 연습 모드(F12), 완료 화면의 광고·알림 동의(Day 5, 플래그 off), 새벽 4시 하루 경계 옵션, 시간대 변경 처리([검증 필요]), 저장 실패·손상 복구 UI(Day 5).

## Capabilities

### New Capabilities
- `home-screen`: 최초 화면인 홈이 보여 주는 오늘 복습 요약(오늘 복습 수·연체 수·과목별 수), 학습 시작, 빈 상태, 상한 초과 안내, 시계 되돌림 경고 표시.
- `date-handling`: 기기 로컬 "오늘"을 언제 다시 정하는지(포그라운드 복귀), 기기 시계가 되돌아간 상황을 어떻게 판정하는지에 대한 규칙.

### Modified Capabilities
- `app-navigation`: 최초 화면을 과목·덱 목록에서 홈으로 바꾸고, 없는 대상 주소의 이동 대상을 홈으로 바꾼다. 세션 완료 후 뒤로가기의 도착 화면을 "세션을 연 화면"으로 일반화한다.
- `study-screens`: 세션 대상에 전체 덱을 추가하고, 완료 화면의 돌아가기 대상과 상한 초과 안내를 정한다.
- `content-screens`: 덱 상세에 하루 상한 초과 안내를 추가한다.
- `data-storage`: 재실행 시 Meta 유지 규칙에서 `lastOpenedDate`는 날짜 규칙에 따라 갱신하도록 바꾼다.

## Impact

- 코드: `reviewq/src/app/router.ts`(home·subjects·studyAll 경로, seed), `reviewq/src/App.tsx`(화면 연결·없는 대상 → 홈), `reviewq/src/screens/Home/`(신설), `reviewq/src/screens/Study/StudySession.tsx`(덱/전체 범위), `reviewq/src/screens/DeckDetail/`(상한 안내), `reviewq/src/screens/messages.ts`(문구), 오늘 날짜·시계 확인 모듈(신설), `reviewq/src/infra/storage/meta.ts`(lastOpenedDate 갱신), `reviewq/src/app/bootstrap.ts`.
- 저장: `bq:meta`의 `lastOpenedDate`를 앱 시작·포그라운드 복귀 때 갱신한다. 저장 키·스키마 버전은 바뀌지 않는다.
- 사용자 영향: 기존 사용자가 `#/`로 열면 과목·덱 목록 대신 홈이 보인다. 데이터 이전은 필요 없다.
- 의존성 추가 없음. 도메인 로직(`queue`·`session`)은 그대로 쓴다.
