# Spec Delta

## Purpose

화면이 기준으로 삼는 기기 로컬 "오늘"을 언제 다시 정하는지와, 기기 시계가 과거로 돌아간 상황을 어떻게 판정하고 기록하는지 정의한다.

## ADDED Requirements

### Requirement: 포그라운드 복귀 시 오늘 재계산
앱이 백그라운드에서 다시 보이게 되면 시스템은 기기 로컬 오늘 날짜를 다시 구하고, 오늘 날짜에 따라 달라지는 화면 값(오늘 복습 수, 연체 수, 다음 복습일 표시)을 새 날짜로 갱신해야 한다(SHALL). 진행 중인 학습 세션의 세션 날짜와 카드 순서는 바꾸어서는 안 된다(MUST NOT).

#### Scenario: 자정을 넘겨 복귀 (S-09)
- **WHEN** 2026-10-26 23:50에 홈을 띄워 둔 채 백그라운드로 보냈다가 2026-10-27 00:10에 다시 연다
- **THEN** 홈의 오늘 복습 수는 2026-10-27 기준으로 다시 계산되어 보인다

#### Scenario: 세션 중 복귀
- **WHEN** 2026-10-26에 시작한 세션을 진행하다 자정 이후 앱으로 돌아온다
- **THEN** 세션은 같은 카드 순서로 이어지고 판정은 2026-10-26 날짜로 반영된다

### Requirement: 시계 되돌림 판정
앱 시작 또는 포그라운드 복귀 시 오늘이 저장된 마지막으로 연 날보다 이전이면 시스템은 시계가 되돌아간 상태로 판정해야 한다(SHALL). 이때 마지막으로 연 날을 갱신해서는 안 되며(MUST NOT), 카드의 다음 복습일도 바꾸지 않는다. 오늘이 마지막으로 연 날과 같거나 이후이면 되돌림이 아니며, 마지막으로 연 날을 오늘로 갱신해 저장해야 한다(SHALL).

#### Scenario: 정상 진행
- **WHEN** 마지막으로 연 날이 2026-10-25이고 2026-10-26에 앱을 연다
- **THEN** 되돌림이 아니고 마지막으로 연 날은 2026-10-26으로 저장된다

#### Scenario: 되돌림 (S-10)
- **WHEN** 마지막으로 연 날이 2026-10-26이고 기기 날짜를 2026-10-20으로 바꾼 뒤 앱을 연다
- **THEN** 되돌림으로 판정되고 마지막으로 연 날은 2026-10-26으로 남으며, 다음 복습일이 미래인 카드는 오늘 큐에 나오지 않는다

#### Scenario: 되돌림 해소
- **WHEN** 되돌림으로 판정된 뒤 기기 날짜를 2026-10-26으로 바로잡고 앱으로 돌아온다
- **THEN** 되돌림 판정이 풀린다
