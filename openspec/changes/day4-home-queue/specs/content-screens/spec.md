# Spec Delta

## MODIFIED Requirements

### Requirement: 덱 상세
덱 상세 화면은 덱 이름, 카드 목록(질문 미리보기와 다음 복습일), 카드 추가 동작을 보여 주어야 한다(SHALL). 카드를 누르면 그 카드의 편집 화면으로 이동해야 한다. 카드가 없으면 빈 상태 안내와 카드 추가 동작을 함께 보여 주어야 한다(MUST). 오늘 복습할 카드가 있으면 그 수와 함께 이 덱의 학습 세션을 시작하는 동작을 보여 주고, 없으면 오늘 복습할 카드가 없다는 안내를 보여 주어야 한다(SHALL). 이 덱의 오늘 복습 대상이 하루 상한을 넘으면 나머지 수가 다음 날 이어서 나온다는 안내를 함께 보여 주어야 한다(SHALL).

#### Scenario: 카드 목록
- **WHEN** 카드 2장이 있는 덱의 상세 화면을 연다
- **THEN** 두 카드의 질문 미리보기와 다음 복습일이 보인다

#### Scenario: 빈 덱
- **WHEN** 카드가 없는 덱의 상세 화면을 연다
- **THEN** 카드가 없다는 안내와 카드 추가 동작이 보인다

#### Scenario: 학습 진입
- **WHEN** 오늘 복습할 카드가 2장인 덱의 상세 화면에서 학습 동작을 누른다
- **THEN** 오늘 복습 2장이 표시되어 있고, 누르면 이 덱의 학습 세션 화면이 열린다

#### Scenario: 오늘 복습 없음
- **WHEN** 모든 카드의 다음 복습일이 내일 이후인 덱의 상세 화면을 연다
- **THEN** 학습 시작 동작 대신 오늘 복습할 카드가 없다는 안내가 보인다

#### Scenario: 덱 상한 초과
- **WHEN** 오늘 복습 대상이 120장인 덱의 상세 화면을 연다
- **THEN** 오늘 복습 120장과 함께 나머지 20장은 내일 이어서 나온다는 안내가 보인다
