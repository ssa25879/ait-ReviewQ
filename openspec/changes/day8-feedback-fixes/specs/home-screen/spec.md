# Spec Delta

## MODIFIED Requirements

### Requirement: 과목별 요약
홈 화면은 과목마다 그 과목 덱들의 오늘 복습 수("오늘 N장")와 전체 카드 수("전체 M장")를 함께 보여 주고, 과목·덱 목록 화면으로 가는 동작을 제공해야 한다(SHALL). 오늘 복습 수가 0이어도 전체 카드 수로 카드가 있다는 것을 알 수 있어야 한다.

#### Scenario: 과목별 오늘 복습 수
- **WHEN** 과목 "영어"에 카드 5장 중 오늘 복습 2장, 과목 "수학"에 카드 3장 중 오늘 복습 0장이 있다
- **THEN** 홈에 "영어 오늘 2장 · 전체 5장", "수학 오늘 0장 · 전체 3장"이 보인다

#### Scenario: 과목·덱 관리 진입
- **WHEN** 홈에서 과목 행을 누른다
- **THEN** 과목·덱 목록 화면이 열리고, 뒤로가기를 누르면 홈으로 돌아온다
