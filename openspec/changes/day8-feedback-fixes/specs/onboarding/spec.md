# Spec Delta

## ADDED Requirements

### Requirement: 가이드 중 기기 뒤로가기
가이드 화면이 열려 있는 동안 시스템은 토스 내비게이션 바의 뒤로가기와 Android 백버튼을 직접 받아, 가이드를 연 화면(처음 실행이면 홈, 설정에서 다시 보기면 설정)으로 돌아가야 한다(SHALL). 이때 미니앱이 종료되어서는 안 된다(MUST NOT). 가이드가 열려 있는 동안 iOS 스와이프 뒤로가기는 끄고, 가이드를 벗어나면 다시 켠다. 본 기록은 저장하지 않는다.

#### Scenario: 처음 실행 가이드에서 기기 뒤로가기
- **WHEN** 처음 실행 가이드에서 토스 내비게이션 바의 뒤로가기를 누른다
- **THEN** 홈이 보이고 미니앱은 닫히지 않는다

#### Scenario: 다시 보기에서 기기 뒤로가기
- **WHEN** 설정에서 연 가이드에서 Android 백버튼을 누른다
- **THEN** 설정 화면이 보인다

#### Scenario: 가이드를 벗어나면 기본 동작 복귀
- **WHEN** 가이드를 끝내고 홈에서 기기 뒤로가기를 누른다
- **THEN** 가이드의 뒤로가기 처리는 해제되어 있고 플랫폼 기본 동작(미니앱 종료)이 일어난다
