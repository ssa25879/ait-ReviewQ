# Spec Delta

## MODIFIED Requirements

### Requirement: 진행 표시
세션은 진행을 두 구간으로 나눠 알려야 한다(SHALL). 첫 회차에는 현재 카드 순번과 세션 시작 카드 수를 알리고, 이 전체 수는 재출제가 생겨도 바뀌지 않는다. 첫 회차 동안 기억 못 함으로 판정한 카드 수(다시 볼 카드 수)도 함께 알린다. 첫 회차가 끝나 재출제 카드를 볼 때는 다시 보기 구간의 순번과 재출제 카드 수를 따로 알린다.

#### Scenario: 진행 수
- **WHEN** 카드 3장 세션에서 두 번째 카드를 보고 있다
- **THEN** 진행은 첫 회차 2/3이다

#### Scenario: 재출제가 생겨도 전체 수 고정
- **WHEN** 카드 3장 세션에서 첫 카드를 기억 못 함으로 판정한다
- **THEN** 진행은 첫 회차 2/3이고 다시 볼 카드는 1장이다

#### Scenario: 다시 보기 구간
- **WHEN** 카드 3장 세션에서 2장을 기억 못 함으로 판정하고 첫 회차를 마친다
- **THEN** 진행은 다시 보기 1/2이다

### Requirement: 세션 요약
세션이 끝나면 시스템은 일정에 반영된 판정 수(완료 수), 그중 기억함 수, 다시 본 카드 수(첫 판정이 기억 못 함이라 재출제된 카드 수), 세션 날짜 다음 날에 복습 예정인 카드 수(전체 덱 기준)를 알려야 한다(SHALL).

#### Scenario: 요약
- **WHEN** 카드 3장 세션에서 2장 기억함, 1장 기억 못 함(재출제 기억함)으로 끝난다
- **THEN** 완료 3, 기억함 2, 다시 본 카드 1이고, 내일 예정 수에는 기억 못 한 카드와 stage 1로 오른 카드가 포함된다
