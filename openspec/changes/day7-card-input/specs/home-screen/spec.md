# Spec Delta

## MODIFIED Requirements

### Requirement: 홈 빈 상태
카드가 하나도 없으면 홈 화면은 과목·덱을 만들고 카드를 추가하라는 첫 사용 안내와 과목·덱 목록으로 가는 동작, 예시 카드로 둘러보는 보조 동작을 보여 주어야 한다(SHALL). 카드는 있지만 오늘 복습할 카드가 없으면 오늘 복습할 카드가 없다는 안내를 보여 주고 학습 시작 동작을 보여서는 안 된다(MUST NOT). 진입하자마자 바텀시트나 대화상자를 띄워서는 안 된다(MUST NOT).

#### Scenario: 첫 사용
- **WHEN** 카드가 하나도 없는 상태에서 앱을 연다
- **THEN** 홈에 첫 사용 안내와 과목·덱 목록으로 가는 버튼, "예시 카드로 둘러보기"가 보이고 대화상자는 열리지 않는다

#### Scenario: 오늘 복습 없음
- **WHEN** 모든 카드의 다음 복습일이 내일 이후다
- **THEN** 홈에 오늘 복습할 카드가 없다는 안내가 보이고 학습 시작 버튼은 없다
