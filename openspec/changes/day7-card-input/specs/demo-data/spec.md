# Spec Delta

## Purpose

실기기 검증 같은 테스트에서 손으로 데이터를 입력하지 않도록, 테스트 빌드에서만 학습 기록이 있는 데모 데이터를 채우는 기능과 출시 빌드에서 제외되는 조건을 정의한다.

## ADDED Requirements

### Requirement: 데모 데이터 플래그
데모 데이터 플래그를 켜서 만든 빌드에서만 설정 화면에 "데모 데이터 채우기" 동작을 보여 주어야 한다(SHALL). 플래그의 기본값은 꺼짐이고, 꺼진 빌드에는 이 동작의 화면과 데모 데이터 내용이 번들에 들어가서는 안 된다(MUST NOT).

#### Scenario: 기본 빌드
- **WHEN** 플래그를 지정하지 않은 빌드로 설정 화면을 연다
- **THEN** "데모 데이터 채우기"가 없고, 빌드 산출물에 데모 데이터 내용이 없다

#### Scenario: 플래그 빌드
- **WHEN** 데모 데이터 플래그를 켠 빌드로 설정 화면을 연다
- **THEN** "데모 데이터 채우기"가 보인다

### Requirement: 데모 데이터 채우기
"데모 데이터 채우기"를 누르면 지금 데이터가 데모 데이터로 바뀐다는 확인을 받은 뒤, 백업 가져오기와 같은 방식으로 과목·덱·카드·학습 기록을 데모 데이터로 바꾸고 홈을 열어야 한다(SHALL). 데모 데이터는 과목 3개 이상, 오늘 복습할 카드, 다음 복습일이 미래인 카드, 최근 7일 안의 학습 기록을 포함한다. 취소하면 아무것도 바꾸지 않는다.

#### Scenario: 채우기
- **WHEN** 플래그 빌드에서 "데모 데이터 채우기"를 누르고 확인한다
- **THEN** 홈에 과목 3개 이상과 오늘 복습 카드 수가 보이고, 통계의 최근 7일 학습에 0이 아닌 날이 있다

#### Scenario: 취소
- **WHEN** 확인에서 취소한다
- **THEN** 저장 데이터가 그대로다
