# Spec Delta

## ADDED Requirements

### Requirement: 리뷰 로그 월별 저장
시스템은 판정 기록을 판정일이 속한 달의 키(`bq:logs:{YYYY-MM}`)에 저장해야 한다(SHALL). 기록이 추가된 달의 키만 저장하고, 다른 달의 키는 저장하지 않는다.

#### Scenario: 이번 달 기록 추가
- **WHEN** 2026-10-26에 판정해 기록이 1건 추가된다
- **THEN** `bq:logs:2026-10`만 저장되고 다른 로그 키는 저장되지 않는다

### Requirement: 리뷰 로그 로드
앱이 시작되면 시스템은 기기 로컬 날짜 기준 이번 달과 지난달의 로그 키를 불러와야 한다(SHALL). 값이 없는 키는 빈 목록으로 보고, JSON으로 읽히지 않으면 덮어쓰지 않고 로드 실패로 알려야 한다(MUST).

#### Scenario: 연초 로드
- **WHEN** 2027-01-05에 앱이 시작된다
- **THEN** `bq:logs:2027-01`과 `bq:logs:2026-12`를 불러온다

#### Scenario: 재실행 후 기록 유지
- **WHEN** 판정 기록 2건을 남기고 앱을 다시 시작한다
- **THEN** 같은 기록 2건이 로드된다

### Requirement: 판정 즉시 저장
판정이 반영되면 시스템은 지연 저장을 기다리지 않고 대기 중인 모든 변경을 즉시 저장해야 한다(SHALL). 판정 직후 앱이 강제 종료되어도 판정이 남게 하기 위해서다.

#### Scenario: 판정 직후 종료 (D-01)
- **WHEN** 카드를 판정하고 400ms가 지나기 전에 저장 상태를 확인한다
- **THEN** 카드 일정과 판정 기록이 이미 저장소에 있다
