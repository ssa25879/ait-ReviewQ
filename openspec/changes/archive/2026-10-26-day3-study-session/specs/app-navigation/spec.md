# Spec Delta

## ADDED Requirements

### Requirement: 학습 세션 중 뒤로가기 확인
학습 세션에 판정할 카드가 남아 있을 때 뒤로가기를 하면 시스템은 바로 화면을 떠나지 않고 학습을 그만둘지 확인해야 한다(SHALL). 토스 내비게이션 바, Android 시스템 백버튼, 브라우저 뒤로가기가 모두 같은 확인을 띄워야 한다. 확인하면 직전 화면으로 돌아가고, 취소하면 같은 카드 상태에 머문다. 학습 완료 화면과 빈 큐 화면에서는 확인 없이 돌아가야 한다(MUST).

#### Scenario: 세션 중 뒤로가기 후 그만하기
- **WHEN** 카드 3장 세션에서 1장을 판정한 뒤 뒤로가기를 누르고 확인에서 그만하기를 고른다
- **THEN** 덱 상세 화면으로 돌아가고 판정한 1장의 결과는 저장되어 있다

#### Scenario: 세션 중 뒤로가기 후 취소
- **WHEN** 정답을 확인한 카드에서 뒤로가기를 누르고 확인에서 취소를 고른다
- **THEN** 학습 세션 화면의 같은 카드가 정답이 보이는 상태로 남고, 이어서 판정할 수 있다

#### Scenario: 완료 후 뒤로가기
- **WHEN** 학습 완료 화면에서 뒤로가기를 누른다
- **THEN** 확인 없이 덱 상세 화면으로 돌아간다
