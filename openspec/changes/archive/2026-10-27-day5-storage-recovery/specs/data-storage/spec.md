# Spec Delta

## MODIFIED Requirements

### Requirement: 앱 데이터 로드
앱이 시작되면 시스템은 과목 목록, 덱 목록, 그리고 덱 목록에 있는 각 덱의 카드 목록을 저장소에서 불러와야 한다(SHALL). 저장된 값이 없는 키는 빈 목록으로 본다. 저장된 값이 형식 검증(data-recovery "저장 데이터 형식 검증")을 통과하지 못하면 덮어쓰지 않고, 손상된 키 목록과 함께 로드 실패로 알려야 한다(MUST).

#### Scenario: 첫 실행
- **WHEN** 저장소에 과목·덱·카드 키가 하나도 없는 상태에서 앱이 시작된다
- **THEN** 과목·덱·카드가 모두 빈 상태로 로드된다

#### Scenario: 재실행
- **WHEN** 과목 1개, 덱 2개, 덱별 카드가 저장된 뒤 앱을 다시 시작한다
- **THEN** 같은 과목·덱·카드가 로드된다

#### Scenario: 손상된 카드 키
- **WHEN** 한 덱의 카드 키 값이 JSON이 아니다
- **THEN** 로드가 실패로 끝나고 실패 결과에 그 카드 키가 들어 있으며 그 키의 저장 값은 바뀌지 않는다

#### Scenario: 형식이 틀린 덱 목록
- **WHEN** 덱 목록 키가 JSON 목록이지만 한 덱의 `name`이 31자다
- **THEN** 로드가 실패로 끝나고 실패 결과에 덱 목록 키가 들어 있다

### Requirement: 리뷰 로그 로드
앱이 시작되면 시스템은 기기 로컬 날짜 기준 이번 달과 지난달의 로그 키를 불러와야 한다(SHALL). 값이 없는 키는 빈 목록으로 보고, 형식 검증을 통과하지 못하면 덮어쓰지 않고 손상된 키 목록과 함께 로드 실패로 알려야 한다(MUST).

#### Scenario: 연초 로드
- **WHEN** 2027-01-05에 앱이 시작된다
- **THEN** `bq:logs:2027-01`과 `bq:logs:2026-12`를 불러온다

#### Scenario: 재실행 후 기록 유지
- **WHEN** 판정 기록 2건을 남기고 앱을 다시 시작한다
- **THEN** 같은 기록 2건이 로드된다

#### Scenario: 날짜 형식이 틀린 기록
- **WHEN** 이번 달 로그 키의 한 기록의 `date`가 `2026/10/26`이다
- **THEN** 로드가 실패로 끝나고 실패 결과에 그 로그 키가 들어 있다
