# Spec Delta

## MODIFIED Requirements

### Requirement: 로딩과 로드 실패 표시
저장 데이터를 불러오는 동안 시스템은 불러오는 중임을 알려야 한다(SHALL). 불러오기에 실패하면 생성·수정·삭제 동작을 제공해서는 안 되며(MUST NOT), 손상이면 복구 화면을, 저장소 읽기 실패면 다시 시도 안내를 보여 주어야 한다(SHALL)(data-recovery "복구 화면", "저장소 읽기 실패"). 어떤 실패 화면도 다음 동작이 없는 막다른 화면이어서는 안 된다(MUST NOT).

#### Scenario: 로드 실패
- **WHEN** 저장된 카드 데이터가 손상되어 불러오기에 실패한다
- **THEN** 복구 화면이 보이고 추가·편집·삭제 버튼이 보이지 않는다

#### Scenario: 읽기 실패
- **WHEN** 저장소 읽기 호출이 실패한다
- **THEN** 데이터를 불러오지 못했다는 안내와 "다시 시도" 버튼이 보인다
