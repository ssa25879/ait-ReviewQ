# Spec Delta

## Purpose

처음 앱을 연 사용자가 복습큐가 무엇을 해 주는지 알고 바로 시작할 수 있도록 하는 최초 실행 가이드의 노출 조건, 구성, 끝내기와 다시 보기를 정의한다.

## ADDED Requirements

### Requirement: 가이드 노출 조건
가이드를 본 기록이 없고 카드가 하나도 없는 상태로 앱을 열면 시스템은 홈 대신 가이드 화면을 열어야 한다(SHALL). 가이드를 본 기록이 있거나 카드가 1장 이상 있으면 가이드를 열지 않는다(MUST NOT). 가이드는 대화상자가 아니라 전체 화면이다.

#### Scenario: 처음 실행
- **WHEN** 저장 데이터가 없는 상태로 앱을 연다
- **THEN** 가이드 첫 장이 보이고 홈은 보이지 않는다

#### Scenario: 카드가 이미 있음
- **WHEN** 가이드를 본 기록은 없지만 카드가 있는 상태로 앱을 연다
- **THEN** 홈이 열리고 가이드는 열리지 않는다

### Requirement: 가이드 구성과 이동
가이드는 3장(카드를 만든다 → 복습할 날에 홈에 모인다 → 기억함을 누를수록 간격이 1·3·7·14·30·60일로 늘어난다)으로 구성되어야 한다(SHALL). 각 장에는 진행 표시(예: 1/3)와 "다음" 동작, 마지막 장이 아니면 "건너뛰기" 동작이 있다. 모든 글자는 13px 이상, 버튼은 44px 이상이다.

#### Scenario: 장 넘기기
- **WHEN** 첫 장에서 "다음"을 두 번 누른다
- **THEN** 진행 표시가 3/3이고 마지막 장의 선택지가 보인다

### Requirement: 가이드 끝내기
가이드를 끝내면 시스템은 본 기록을 저장해야 한다(SHALL). 마지막 장의 "예시 카드로 시작"은 예시 과목·단원을 만들고 홈을 연다. "직접 만들기"는 과목·단원 목록을 연다. "건너뛰기"는 홈을 연다. 본 기록이 저장된 뒤에는 앱을 다시 열어도 가이드가 자동으로 열리지 않는다.

#### Scenario: 예시 카드로 시작
- **WHEN** 마지막 장에서 "예시 카드로 시작"을 누른다
- **THEN** 홈에 오늘 복습 10장이 보이고, 다시 열어도 가이드가 열리지 않는다

#### Scenario: 직접 만들기
- **WHEN** 마지막 장에서 "직접 만들기"를 누른 뒤 뒤로가기를 누른다
- **THEN** 과목·단원 목록이 열렸다가 홈으로 돌아온다

#### Scenario: 건너뛰기
- **WHEN** 첫 장에서 "건너뛰기"를 누르고 앱을 다시 연다
- **THEN** 홈이 열리고 가이드는 열리지 않는다

### Requirement: 가이드 다시 보기
설정 화면은 "사용 방법 보기" 동작을 제공해야 한다(SHALL). 누르면 가이드 첫 장이 열리고, 끝내거나 건너뛰면 설정 화면으로 돌아온다. 카드가 1장 이상 있으면 마지막 장에 "예시 카드로 시작"·"직접 만들기" 대신 "확인" 하나만 보여 준다.

#### Scenario: 설정에서 다시 보기
- **WHEN** 설정에서 "사용 방법 보기"를 누르고 "건너뛰기"를 누른다
- **THEN** 가이드가 열렸다가 설정 화면으로 돌아온다

#### Scenario: 카드가 있을 때 마지막 장
- **WHEN** 카드가 있는 상태에서 가이드 마지막 장까지 넘긴다
- **THEN** "확인"만 보이고, 누르면 가이드를 연 화면으로 돌아온다

### Requirement: 가이드에서 뒤로가기
가이드 화면에서 뒤로가기를 하면 가이드를 연 화면(처음 실행이면 홈)으로 돌아가야 한다(SHALL). 이때 본 기록은 저장하지 않으며, 같은 실행 중에는 가이드를 다시 자동으로 열지 않는다(MUST NOT).

#### Scenario: 처음 실행에서 뒤로가기
- **WHEN** 처음 실행 가이드에서 뒤로가기를 누른다
- **THEN** 홈이 보이고 가이드가 다시 열리지 않는다
