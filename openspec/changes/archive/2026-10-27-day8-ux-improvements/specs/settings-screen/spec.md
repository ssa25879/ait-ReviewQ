# Spec Delta

## MODIFIED Requirements

### Requirement: 설정 진입
홈 화면은 바로가기 타일의 "설정"으로 설정 화면으로 가는 동작을 제공해야 한다(SHALL). 설정 화면에서 뒤로가기를 하면 홈으로 돌아가야 한다. 설정 화면 주소로 바로 열거나 새로고침해도 설정 화면이 열리고, 뒤로가기를 하면 홈으로 간다.

#### Scenario: 홈에서 설정 열기
- **WHEN** 홈에서 설정 타일을 누른 뒤 뒤로가기를 누른다
- **THEN** 설정 화면이 열렸다가 홈으로 돌아온다

#### Scenario: 설정 주소로 바로 열기
- **WHEN** 설정 화면 주소로 앱을 열고 뒤로가기를 누른다
- **THEN** 설정 화면이 보이고, 뒤로가기 후 홈이 보인다

### Requirement: 전체 삭제 실행
최종 확인을 받으면 시스템은 이 앱의 저장 데이터(과목·덱·카드·판정 기록·Meta·자동 백업·격리 원본·가이드 본 기록)를 모두 지우고, 첫 실행과 같은 빈 상태로 홈을 열어야 한다(SHALL). 삭제 전에 저장 대기 중이던 변경이 삭제 뒤에 다시 저장되어서는 안 된다(MUST NOT). 삭제가 실패하면 실패 안내를 보여 주고 다시 시도할 수 있어야 한다.

#### Scenario: 삭제 후 첫 사용 상태
- **WHEN** 과목·단원·카드와 판정 기록이 있는 상태에서 전체 삭제를 끝낸다
- **THEN** 홈에 첫 사용 안내가 보이고, `bq:` 키는 새로 만든 `bq:meta`(알림 기록 없음)만 남는다

#### Scenario: 저장 대기 중 삭제
- **WHEN** 카드를 편집한 직후(저장 대기 중) 설정에서 전체 삭제를 끝내고 잠시 기다린다
- **THEN** 편집했던 카드가 저장소에 다시 생기지 않는다

#### Scenario: 삭제 실패
- **WHEN** 저장소 전체 삭제가 실패한다
- **THEN** 삭제하지 못했다는 안내와 다시 시도 동작이 보이고, 앱은 막다른 화면이 되지 않는다

#### Scenario: 삭제 후 재실행
- **WHEN** 전체 삭제 뒤 앱을 다시 연다
- **THEN** 처음 실행처럼 최초 실행 가이드가 열리고, 건너뛰면 과목·단원·카드가 없는 첫 사용 홈이 보인다
