# Spec Delta

## Purpose

통계 화면이 판정 기록과 카드 단계로부터 어떤 학습 수치를 계산해 보여 주는지, 그리고 어디서 들어가고 데이터가 없을 때 무엇을 보여 주는지 정의한다.

## ADDED Requirements

### Requirement: 통계 진입
홈 화면은 통계 화면으로 가는 동작을 제공해야 한다(SHALL). 통계 화면에서 뒤로가기를 하면 홈으로 돌아가야 한다.

#### Scenario: 홈에서 통계 열기
- **WHEN** 홈에서 통계 동작을 누른 뒤 뒤로가기를 누른다
- **THEN** 통계 화면이 열렸다가 홈으로 돌아온다

### Requirement: 오늘 완료 수
통계 화면은 기기 로컬 오늘 날짜로 남은 판정 기록 수를 오늘 완료 수로 보여 주어야 한다(SHALL). 세션의 재출제 판정처럼 기록이 남지 않는 판정은 세지 않는다.

#### Scenario: 오늘 판정 3건
- **WHEN** 오늘 카드 3장을 판정했고 그중 1장은 재출제되어 한 번 더 판정했다
- **THEN** 오늘 완료 수는 3이다

### Requirement: 전체 카드 수와 단계별 분포
통계 화면은 전체 카드 수와, 단계별 카드 수(새 카드·다시 학습, 1일·3일·7일·14일·30일·60일 간격 단계)를 보여 주어야 한다(SHALL). 단계별 수의 합은 전체 카드 수와 같아야 한다(MUST).

#### Scenario: 단계 분포
- **WHEN** 새 카드 2장, 1일 단계 1장, 7일 단계 1장이 있다
- **THEN** 전체 4장이고 새 카드·다시 학습 2, 1일 1, 7일 1, 나머지 단계는 0으로 보인다

### Requirement: 최근 7일 학습 수
통계 화면은 오늘을 포함한 최근 7일의 날짜별 판정 기록 수를 오래된 날부터 순서대로 보여 주어야 한다(SHALL). 기록이 없는 날은 0으로 보인다. 달이 바뀌는 구간에서도 두 달의 기록을 함께 센다(MUST).

#### Scenario: 월 경계
- **WHEN** 오늘이 2026-11-02이고 2026-10-30에 2건, 2026-11-01에 1건, 2026-10-26에 5건의 기록이 있다
- **THEN** 2026-10-27부터 2026-11-02까지 7일이 보이고 10-30은 2, 11-01은 1, 나머지는 0이며 10-26의 기록은 세지 않는다

### Requirement: 통계 빈 상태
카드가 하나도 없으면 통계 화면은 카드를 만들고 학습하면 통계가 쌓인다는 안내를 보여 주어야 한다(SHALL).

#### Scenario: 첫 사용
- **WHEN** 카드가 없는 상태에서 통계 화면을 연다
- **THEN** 빈 상태 안내가 보이고 오류 없이 표시된다
