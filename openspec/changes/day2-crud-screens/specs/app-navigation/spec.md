# Spec Delta

## Purpose

미니앱 안의 화면 이동 규칙을 정의한다. 화면 스택을 히스토리와 맞춰 토스 내비게이션 바·Android 백버튼·브라우저 뒤로가기가 같은 방식으로 동작하게 한다.

## ADDED Requirements

### Requirement: 최초 화면
앱을 처음 열면 시스템은 과목·덱 목록 화면을 보여 주어야 한다(SHALL). 최초 화면에서 뒤로가기를 하면 미니앱이 종료되어야 하며, 시스템은 이 동작을 가로막아서는 안 된다(MUST NOT).

#### Scenario: 앱 진입
- **WHEN** 사용자가 미니앱을 연다
- **THEN** 과목·덱 목록 화면이 보인다

#### Scenario: 최초 화면에서 뒤로가기
- **WHEN** 과목·덱 목록 화면에서 뒤로가기를 누른다
- **THEN** 미니앱이 종료된다

### Requirement: 화면 이동과 뒤로가기
시스템은 화면 이동을 히스토리에 쌓고, 뒤로가기 시 직전 화면으로 돌아가야 한다(SHALL). 토스 내비게이션 바의 뒤로가기, Android 시스템 백버튼, 브라우저 뒤로가기가 같은 결과를 내야 한다. 화면 안에 자체 뒤로가기 버튼을 두어서는 안 된다(MUST NOT).

#### Scenario: 두 단계 이동 후 뒤로가기
- **WHEN** 과목·덱 목록 → 덱 상세 → 카드 편집으로 이동한 뒤 뒤로가기를 두 번 누른다
- **THEN** 덱 상세를 거쳐 과목·덱 목록 화면으로 돌아온다

#### Scenario: 저장 후 복귀
- **WHEN** 카드 편집 화면에서 저장한다
- **THEN** 직전의 덱 상세 화면으로 돌아오고, 뒤로가기를 한 번 더 누르면 과목·덱 목록으로 간다

### Requirement: 새로고침 시 화면 유지
화면을 새로 불러오면 시스템은 직전에 보던 화면을 다시 보여 주어야 한다(SHALL). 그 화면이 가리키는 덱이나 카드가 더 이상 없으면 과목·덱 목록 화면을 보여 주어야 한다(MUST).

#### Scenario: 덱 상세에서 새로고침
- **WHEN** 덱 상세 화면에서 새로고침한다
- **THEN** 같은 덱의 상세 화면이 보인다

#### Scenario: 삭제된 덱 주소
- **WHEN** 존재하지 않는 덱의 상세 화면 주소로 연다
- **THEN** 과목·덱 목록 화면이 보인다
