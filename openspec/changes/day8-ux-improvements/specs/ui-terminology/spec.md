# Spec Delta

## Purpose

과목 아래의 카드 묶음을 화면에서 어떤 말로 부르는지 정해, 학습 앱 사용자에게 익숙한 용어를 일관되게 쓰도록 한다.

## ADDED Requirements

### Requirement: 단원 용어
화면에 보이는 모든 문구(제목·버튼·안내·대화상자·오류·공유 메시지)는 과목 아래의 카드 묶음을 "단원"이라고 불러야 한다(SHALL). "덱"이라는 말을 화면에 보여서는 안 된다(MUST NOT). 저장 데이터 형식·키 이름·코드 이름은 이 규칙의 대상이 아니다.

#### Scenario: 과목 목록
- **WHEN** 과목·단원 목록 화면을 연다
- **THEN** 제목이 "과목·단원"이고 추가 동작이 "단원 추가"이며, 화면 어디에도 "덱"이 없다

#### Scenario: 대화상자와 안내
- **WHEN** 단원 이름 바꾸기·단원 삭제 대화상자와 백업 가져오기 요약을 연다
- **THEN** 모든 문구가 "단원"을 쓰고 "덱"은 없다
