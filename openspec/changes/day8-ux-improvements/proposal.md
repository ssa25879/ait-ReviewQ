# Proposal

## Why

실기기 사용에서 네 가지 불편이 확인됐다. 백업을 불러온 뒤 화면 안 요약을 보고 다시 버튼과 확인 두 번을 눌러야 해서 번거롭다. 홈 맨 아래의 통계·설정 행이 눈에 띄지 않고, 홈이 메인 화면이라는 표시가 없어 뒤로가기로 앱을 나가 버리는 경우가 많다. "덱"은 학습 앱 사용자에게 낯선 말이다. 처음 연 사용자가 앱이 무엇을 해 주는지 알 수 있는 안내가 없다.

## What Changes

- **가져오기 확인 팝업**: "불러오기"(또는 파일 선택)로 내용이 검증되면 바로 팝업을 띄워 요약(과목·단원·카드·학습 기록 수, 내보낸 날짜)과 "지금 데이터가 바뀐다"는 경고를 보여 주고 [취소 | 바꾸기]로 고르게 한다. 화면 안 요약·"이 백업으로 바꾸기" 버튼·2단계 확인은 없앤다.
- **홈 머리말과 바로가기 타일**: 홈 맨 위에 앱 이름과 오늘 날짜를 보여 주고, 오늘 복습 요약 아래에 통계·과목 관리·설정 바로가기 타일 3칸(아이콘 + 이름)을 둔다. 맨 아래의 통계·설정 행은 없앤다. 하단 고정 버튼은 첫 사용이면 "과목·단원 만들기", 오늘 복습이 있으면 "학습 시작"만 둔다(과목 관리는 타일로 옮김).
- **용어 "덱" → "단원"**: 화면에 보이는 모든 문구에서 "덱"을 "단원"으로 바꾼다. 데이터 형식·키·코드 이름은 그대로 둔다.
- **최초 실행 가이드**: 처음 실행(가이드를 본 기록이 없고 카드가 없을 때)하면 홈 대신 가이드 화면을 연다. 3장(카드 만들기 → 오늘 복습 → 간격이 늘어나는 원리)을 "다음"·"건너뛰기"로 넘기고, 마지막 장에서 "예시 카드로 시작"·"직접 만들기"를 고른다. 본 기록은 저장하고, 설정의 "사용 방법 보기"로 다시 볼 수 있다.

범위 밖: 하단 탭 바, 홈에서 뒤로가기 시 종료 확인, 앱 이름 변경, 콘솔 등록 정보·스크린샷 갱신(출시 준비 단계에서 다룸).

## Capabilities

### New Capabilities
- `onboarding`: 최초 실행 가이드의 노출 조건, 구성과 이동, 끝내기 선택지, 본 기록, 다시 보기.
- `ui-terminology`: 화면 문구에서 덱을 "단원"으로 부르는 용어 규칙.

### Modified Capabilities
- `data-import`: 검증 후 요약을 팝업으로 보여 주고 한 번의 선택으로 교체한다(2단계 확인 제거).
- `home-screen`: 머리말(앱 이름·날짜), 바로가기 타일, 하단 버튼 구성, 첫 사용 버튼 이름.
- `stats-screen`: 통계 진입을 홈 바로가기 타일로 바꾼다.
- `settings-screen`: 설정 진입을 홈 바로가기 타일로 바꾸고, 전체 삭제 후 다시 열면 가이드가 열리도록 시나리오를 고친다("사용 방법 보기"는 onboarding에 정의).

## Impact

- 코드: `reviewq/src/screens/Settings/Settings.tsx`(가져오기 팝업·사용 방법 보기), `reviewq/src/screens/Home/`(머리말·타일·하단 버튼), `reviewq/src/components/icons.tsx`(통계·과목·설정 아이콘), `reviewq/src/screens/Guide/`(신설), `reviewq/src/app/router.ts`(경로 `guide`), `reviewq/src/App.tsx`(최초 실행 시 가이드로 전환), `reviewq/src/app/bootstrap.ts`·`infra/storage/keys.ts`(가이드 본 기록 키), `reviewq/src/screens/messages.ts`와 화면 파일의 "덱" 문구, `handoff/e2e/*.mjs`(문구·첫 화면 기대값).
- 저장: 새 키 `bq:guide`(가이드를 봤는지). 형식 버전 변경 없음.
- 콘솔: 등록용 스크린샷·상세 설명에 "덱"이 있어 출시 전에 다시 만들어야 한다.
