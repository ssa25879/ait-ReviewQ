# Spec Delta

## ADDED Requirements

### Requirement: 백업 코드 공유
설정의 백업 섹션은 "백업 코드 공유"를 기본 동작으로 제공해야 한다(SHALL). 누르면 내보내기 문서를 압축한 한 덩어리 글자(백업 코드)를 만들어, 가져오는 방법 안내와 함께 기기 공유 시트로 보낸다. 같은 코드를 화면에도 읽기 전용으로 보여 준다. 공유 시트를 열지 못해도 코드는 화면에 남아야 한다. 이 기능은 새 권한을 요구해서는 안 된다(MUST NOT).

#### Scenario: 코드 공유
- **WHEN** "백업 코드 공유"를 누른다
- **THEN** 백업 코드가 든 메시지로 공유 시트가 1회 열리고, 화면에 같은 코드가 보인다

#### Scenario: 공유 실패
- **WHEN** 공유 시트를 여는 데 실패한다
- **THEN** 공유하지 못했다는 안내와 함께 코드가 화면에 보이고 저장 데이터는 바뀌지 않는다

#### Scenario: 코드 왕복
- **WHEN** 만든 백업 코드를 해독한다
- **THEN** 내보내기 문서와 같은 내용이 나오고 형식 검증을 통과한다

### Requirement: 백업 코드 복사
백업 코드가 화면에 보이면 "코드 복사" 동작을 함께 제공해야 한다(SHALL). 누르면 코드를 클립보드에 복사하고 복사했다는 안내를 보여 준다. 복사에 실패하면 코드를 길게 눌러 직접 복사하라는 안내를 보여 준다.

#### Scenario: 복사
- **WHEN** "코드 복사"를 누른다
- **THEN** 클립보드에 백업 코드가 들어가고 복사했다는 안내가 보인다

## MODIFIED Requirements

### Requirement: 내보내기 내용
설정 화면의 "백업 코드 공유"나 "파일로 저장"을 누르면 시스템은 과목·덱·카드(다음 복습일 등 일정 포함)와 저장된 모든 달의 판정 기록을 하나의 JSON 문서로 만들어야 한다(SHALL). 문서에는 내보내기 형식 버전, 내보낸 시각, 앱 데이터 형식 버전을 넣는다. 저장 대기 중인 변경이 있으면 먼저 저장한 뒤의 값을 내보낸다. 알림 동의 기록·기기 식별자·자동 백업·격리 원본은 넣지 않는다(MUST NOT).

#### Scenario: 전체 내용 포함 (D-06 일부)
- **WHEN** 과목 2개·덱 3개·카드 10장과 이번 달·석 달 전 판정 기록이 있는 상태에서 내보낸다
- **THEN** 문서의 과목·덱·카드가 저장소 값과 같고, 판정 기록에 두 달치가 모두 들어 있다

#### Scenario: 개인 식별 정보 제외
- **WHEN** 알림 동의 기록이 있는 상태에서 내보낸다
- **THEN** 문서에 알림 동의 기록과 기기 식별자가 없다

#### Scenario: 저장 대기 중 내보내기
- **WHEN** 카드 정답을 고친 직후(저장 대기 중) 내보낸다
- **THEN** 문서의 그 카드 정답이 고친 값이다

### Requirement: 파일로 저장
기기가 파일 저장을 지원하면 시스템은 보조 동작 "파일로 저장"으로 문서를 날짜가 들어간 `.json` 파일로 저장(기기에 따라 공유 시트로 전달)하고, 요청했다는 안내를 보여 주어야 한다(SHALL). 저장하는 동안 버튼을 다시 누를 수 없다. 이 기능은 새 권한을 요구해서는 안 된다(MUST NOT).

#### Scenario: 파일 저장 성공
- **WHEN** 파일 저장을 지원하는 환경에서 "파일로 저장"을 누른다
- **THEN** 파일 이름이 `reviewq-backup-YYYY-MM-DD.json` 형식이고 내용이 내보낸 문서인 파일 저장이 1회 요청되며, 안내가 보인다

#### Scenario: 연타
- **WHEN** "파일로 저장"을 빠르게 두 번 누른다
- **THEN** 파일 저장은 1회만 요청된다

### Requirement: 파일 저장 불가 시 직접 복사
기기가 파일 저장을 지원하지 않거나 파일 저장이 실패하면 시스템은 같은 문서를 설정 화면에 읽기 전용 텍스트로 보여 주어 사용자가 직접 선택해 복사할 수 있게 해야 한다(SHALL). 파일 저장이 실패한 경우에는 실패 안내를 함께 보여 준다. 어느 경우에도 저장 데이터는 바뀌지 않는다.

#### Scenario: 미지원 환경
- **WHEN** 파일 저장을 지원하지 않는 환경에서 "파일로 저장"을 누른다
- **THEN** 내보낸 문서가 읽기 전용 텍스트로 보이고 파일 저장은 요청되지 않는다

#### Scenario: 저장 실패
- **WHEN** 파일 저장이 실패한다
- **THEN** 저장하지 못했다는 안내와 함께 문서 텍스트가 보이고, 저장소 값은 내보내기 전과 같다
