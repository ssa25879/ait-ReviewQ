# Spec Delta

## MODIFIED Requirements

### Requirement: 가져오기 진입과 입력
설정의 백업 섹션은 "백업 가져오기" 동작을 제공해야 한다(SHALL). 누르면 백업 코드나 백업 내용을 붙여넣는 입력란과, 백업 파일을 고르는 동작을 함께 보여 준다. 입력란에는 백업 코드만, 코드가 든 공유 메시지 전체, 또는 내보낸 JSON 내용을 붙여넣을 수 있다. 입력만으로는 저장 데이터를 바꾸지 않는다.

#### Scenario: 파일 선택
- **WHEN** "백업 가져오기"에서 내보내기 파일을 고른다
- **THEN** 파일 내용을 읽어 검증 단계로 넘어가고 저장 데이터는 그대로다

#### Scenario: 붙여넣기
- **WHEN** 입력란에 내보낸 백업 내용을 붙여넣고 불러오기를 누른다
- **THEN** 붙여넣은 내용으로 검증 단계로 넘어간다

#### Scenario: 공유 메시지 붙여넣기
- **WHEN** 안내 문구와 백업 코드가 함께 든 공유 메시지 전체를 붙여넣고 불러오기를 누른다
- **THEN** 메시지에서 코드를 찾아 풀고 검증 단계로 넘어간다

### Requirement: 백업 검증과 요약
시스템은 불러온 내용이 내보내기 형식 검증을 통과하고, 모든 덱의 과목과 모든 카드의 덱이 문서 안에 있을 때만 가져오기를 허용해야 한다(SHALL). 통과하면 과목·덱·카드·학습 기록 수와 내보낸 날짜를 보여 준다. JSON이 아니거나, 백업 코드를 풀 수 없거나, 검증에 실패하거나, 이 앱보다 새 형식 버전·데이터 버전이면 이유를 알리고 가져오기를 허용하지 않는다(MUST NOT).

#### Scenario: 정상 백업
- **WHEN** 과목 2·덱 3·카드 10장·기록 4건이 든 내보내기 파일을 불러온다
- **THEN** "과목 2개, 덱 3개, 카드 10장, 학습 기록 4건"과 내보낸 날짜가 보이고 가져오기 동작이 열린다

#### Scenario: 잘못된 내용
- **WHEN** JSON이 아닌 글이나 형식이 틀린 문서를 불러온다
- **THEN** 백업 파일이 아니라는 안내가 보이고 가져오기 동작은 열리지 않는다

#### Scenario: 잘린 백업 코드
- **WHEN** 끝부분이 잘린 백업 코드를 불러온다
- **THEN** 코드가 올바르지 않으니 전체를 복사했는지 확인하라는 안내가 보이고 가져오기 동작은 열리지 않는다

#### Scenario: 참조 불일치
- **WHEN** 덱이 가리키는 과목이 문서에 없는 백업을 불러온다
- **THEN** 백업 내용이 맞지 않는다는 안내가 보이고 가져오기 동작은 열리지 않는다

#### Scenario: 새 버전 백업
- **WHEN** 형식 버전이나 데이터 버전이 이 앱보다 높은 백업을 불러온다
- **THEN** 앱을 업데이트한 뒤 가져오라는 안내가 보이고 가져오기 동작은 열리지 않는다
