# review-notification Specification

## Purpose
복습 알림 수신 동의를 언제 어떤 조건에서 요청하는지, 동의 결과를 어떻게 기록하고 다시 묻지 않는지 정의한다.

## Requirements

### Requirement: 알림 기능 플래그
알림 기능 플래그가 꺼져 있으면 시스템은 알림 동의 버튼을 어떤 화면에도 보여 주지 않고 동의 요청을 호출하지 않아야 한다(MUST NOT). 플래그의 기본값은 꺼짐이다.

#### Scenario: 플래그 off (N-08)
- **WHEN** 알림 플래그를 지정하지 않은 빌드로 학습 세션을 마친다
- **THEN** 학습 완료 화면에 "복습 알림 받기" 버튼이 없다

### Requirement: 동의 요청 버튼 노출
알림 플래그가 켜져 있고, 기기가 알림 동의 요청을 지원하고, 알림 템플릿 코드가 설정되어 있고, 아직 동의 기록이 없을 때만 시스템은 학습 완료 화면에 "복습 알림 받기" 보조 버튼을 보여 주어야 한다(SHALL). 이 버튼은 돌아가기 버튼보다 약한 스타일이다. 앱 진입 직후나 다른 화면에서는 동의를 요청하거나 대화상자를 띄워서는 안 된다(MUST NOT).

#### Scenario: 미지원 기기 (N-01)
- **WHEN** 알림 플래그를 켰지만 동의 요청을 지원하지 않는 환경에서 학습 세션을 마친다
- **THEN** "복습 알림 받기" 버튼이 없다

#### Scenario: 진입 직후 (N-07)
- **WHEN** 알림 플래그를 켠 빌드로 앱을 연다
- **THEN** 동의 요청이 호출되지 않고 대화상자도 열리지 않는다

### Requirement: 동의 결과 기록
"복습 알림 받기"를 눌러 동의 결과를 받으면 시스템은 결과를 Meta의 알림 동의 기록에 저장해야 한다(SHALL). 동의(새 동의 또는 이미 동의)이면 동의함과 동의 시각, 요청 시각을 저장하고 동의했다는 안내를 보여 준다. 거부이면 동의하지 않음과 요청 시각을 저장한다. 기록이 생긴 뒤에는 학습 완료 화면에서 다시 묻지 않는다.

#### Scenario: 동의 (N-02)
- **WHEN** "복습 알림 받기"를 누르고 동의한다
- **THEN** `bq:meta`의 알림 기록이 동의함이고 동의 시각이 있으며, 버튼 대신 동의 안내가 보인다

#### Scenario: 거부 (N-03)
- **WHEN** "복습 알림 받기"를 누르고 거부한 뒤 다음 학습 세션을 마친다
- **THEN** 알림 기록이 동의하지 않음이고 요청 시각이 있으며, 학습 완료 화면에 버튼이 다시 보이지 않는다

### Requirement: 동의 요청 실패
동의 요청이 오류로 끝나면 시스템은 기록을 남기지 않고, 요청하지 못했다는 안내와 함께 버튼을 다시 누를 수 있게 두어야 한다(SHALL).

#### Scenario: 요청 오류
- **WHEN** "복습 알림 받기"를 눌렀는데 동의 요청이 오류를 알린다
- **THEN** 알림 기록이 없고 버튼이 그대로 보인다

### Requirement: 거부 후 다른 기능
알림 동의를 거부하거나 요청이 실패해도 시스템의 학습, 과목·덱·카드 관리, 통계는 그대로 동작해야 한다(SHALL).

#### Scenario: 거부 후 학습 (N-05)
- **WHEN** 알림 동의를 거부한 뒤 홈에서 학습을 시작한다
- **THEN** 학습 세션과 판정 저장이 평소처럼 동작한다
