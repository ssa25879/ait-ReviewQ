# study-screens Specification

## Purpose
사용자가 카드를 뒤집고 판정하는 학습 세션 화면과, 세션을 마친 뒤의 학습 완료 화면이 무엇을 보여 주고 어떤 조작을 받는지 정의한다.

## Requirements

### Requirement: 세션 시작
학습 세션 화면이 열리면 시스템은 그 시점의 기기 로컬 날짜를 기준으로 대상(덱 하나 또는 전체 덱)의 오늘 복습 큐를 만들어 세션을 시작해야 한다(SHALL). 세션 도중에 큐를 다시 만들지 않는다.

#### Scenario: 덱에서 학습 시작
- **WHEN** 오늘 복습할 카드가 3장인 덱에서 학습을 시작한다
- **THEN** 첫 카드의 질문이 보이고 진행은 1/3이다

#### Scenario: 세션 중 카드 예정일 변화
- **WHEN** 세션 중 첫 카드를 판정해 그 카드의 다음 복습일이 바뀐다
- **THEN** 세션의 카드 순서와 전체 수는 바뀌지 않는다

#### Scenario: 전체 덱 학습 시작
- **WHEN** 덱 A에 오늘 복습 2장(다음 복습일 2일 전 1장, 오늘 1장), 덱 B에 오늘 복습 1장(다음 복습일 1일 전)이 있을 때 홈에서 학습을 시작한다
- **THEN** 진행은 1/3이고 카드는 다음 복습일이 오래된 순(덱 A 2일 전, 덱 B 1일 전, 덱 A 오늘)으로 나온다

### Requirement: 진행 표시
학습 세션 화면은 첫 회차에 "현재 순번 / 세션 시작 카드 수"를 보여 주고, 기억 못 함으로 판정한 카드가 있으면 "다시 볼 카드 N장"을 함께 보여 주어야 한다(SHALL). 재출제 카드를 볼 때는 "다시 보기 현재 순번 / 재출제 카드 수"로 구간을 구분해 보여 준다. 첫 회차의 전체 수는 홈이나 단원 상세에 보였던 오늘 복습 수(상한으로 빠진 수 제외)와 같아야 한다(MUST).

#### Scenario: 재출제 후 전체 수
- **WHEN** 카드 3장 세션에서 첫 카드를 기억 못 함으로 판정한다
- **THEN** 진행은 2 / 3으로 보이고 "다시 볼 카드 1장"이 함께 보인다

#### Scenario: 다시 보기 구간 표시
- **WHEN** 카드 3장 세션에서 1장을 기억 못 함으로 판정하고 첫 회차를 마친다
- **THEN** 진행은 "다시 보기 1 / 1"로 보인다

### Requirement: 카드 뒤집기
학습 세션 화면은 카드의 질문을 먼저 보여 주고, 카드 영역을 누르면 정답을 함께 보여 주어야 한다(SHALL). 뒤집은 카드를 다시 눌러도 질문 상태로 돌아가지 않는다.

#### Scenario: 정답 확인
- **WHEN** 질문이 보이는 카드 영역을 누른다
- **THEN** 질문과 정답이 함께 보인다

### Requirement: 판정 버튼
학습 세션 화면은 화면 하단에 "기억 못 함"과 "기억함" 버튼을 좌우로 고정해 보여 주어야 한다(SHALL). 정답을 확인하기 전에는 두 버튼이 비활성 상태여야 한다(MUST). 버튼을 누르면 판정이 반영되고 다음 카드의 질문이 보인다.

#### Scenario: 뒤집기 전 버튼
- **WHEN** 카드의 질문만 보이는 상태다
- **THEN** 두 판정 버튼이 비활성 상태이고 눌러도 아무 변화가 없다

#### Scenario: 판정 후 다음 카드
- **WHEN** 정답을 확인하고 "기억함"을 누른다
- **THEN** 그 카드의 다음 복습일이 바뀌고 다음 카드의 질문이 보인다

### Requirement: 판정 연타 방지
판정 버튼을 누른 뒤 다음 카드가 보이기 전까지 시스템은 추가 판정 입력을 무시해야 한다(MUST). 한 번의 탭이 두 장 이상의 카드를 판정해서는 안 된다.

#### Scenario: 빠른 두 번 탭
- **WHEN** 정답을 확인한 카드에서 "기억함"을 매우 빠르게 두 번 누른다
- **THEN** 판정 기록은 1건만 늘고, 다음 카드는 질문 상태로 판정되지 않은 채 보인다

### Requirement: 학습 완료 화면
세션의 마지막 카드를 판정하면 시스템은 학습 완료 화면을 보여 주어야 한다(SHALL). 완료 화면은 완료 수, 기억함 비율, 내일 복습 예정 수를 보여 주고, 다시 본 카드가 있으면 그 수를 함께 보여 주며, 세션을 연 화면(덱 세션은 덱 상세, 전체 덱 세션은 홈)으로 돌아가는 동작을 제공해야 한다. 세션을 시작할 때 하루 상한 때문에 빠진 카드가 있었으면 그 수가 다음 날 이어서 나온다는 안내를 함께 보여 주어야 한다(SHALL).

#### Scenario: 세션 완료
- **WHEN** 카드 2장 세션에서 1장 기억함, 1장 기억 못 함 후 재출제 카드까지 판정한다
- **THEN** 완료 2장, 기억함 50%, 다시 본 카드 1장, 내일 예정 2장이 보이고 단원으로 돌아가는 버튼이 있다

#### Scenario: 다시 본 카드가 없으면 숨김
- **WHEN** 카드 2장 세션에서 모두 기억함으로 판정한다
- **THEN** 완료 화면에 다시 본 카드 항목이 없다

#### Scenario: 덱으로 돌아가기
- **WHEN** 완료 화면에서 돌아가기 버튼을 누른다
- **THEN** 덱 상세 화면이 보이고 판정한 카드의 다음 복습일이 갱신되어 있다

#### Scenario: 전체 덱 세션 완료 후 홈으로
- **WHEN** 홈에서 시작한 세션을 마치고 완료 화면의 돌아가기 버튼을 누른다
- **THEN** 홈 화면이 보이고 오늘 복습 수가 판정 결과대로 줄어 있다

#### Scenario: 상한 초과 세션 완료
- **WHEN** 오늘 복습 대상 130장 중 100장으로 시작한 세션을 마친다
- **THEN** 완료 화면에 나머지 30장은 내일 이어서 나온다는 안내가 보인다

### Requirement: 빈 큐
학습 세션 화면을 열었을 때 오늘 복습할 카드가 없으면 시스템은 복습할 카드가 없다는 안내와 세션을 연 화면(덱 세션은 덱 상세, 전체 덱 세션은 홈)으로 돌아가는 동작을 보여 주어야 한다(SHALL).

#### Scenario: 이미 모두 복습한 덱
- **WHEN** 오늘 복습할 카드가 0장인 덱의 학습 화면 주소를 연다
- **THEN** 복습할 카드가 없다는 안내와 덱으로 돌아가는 버튼이 보인다

#### Scenario: 전체 덱 빈 큐
- **WHEN** 오늘 복습할 카드가 0장일 때 전체 덱 학습 화면 주소를 연다
- **THEN** 복습할 카드가 없다는 안내와 홈으로 돌아가는 버튼이 보인다

### Requirement: 세션 화면 새로고침
학습 세션 화면을 새로 불러오면 시스템은 그 시점의 오늘 복습 큐로 새 세션을 시작해야 한다(SHALL). 새로고침 전에 판정한 카드의 결과는 유지된다.

#### Scenario: 세션 중 새로고침
- **WHEN** 카드 3장 세션에서 1장을 기억함으로 판정한 뒤 새로고침한다
- **THEN** 남은 2장으로 새 세션이 시작되고 진행은 1/2이다
