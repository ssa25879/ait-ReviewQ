# bulk-card-input Specification

## Purpose
사용자가 메모장이나 스프레드시트에 정리해 둔 질문·정답 목록을 붙여넣어 한 덱에 카드 여러 장을 한 번에 만드는 기능의 입력 규칙, 미리 보기와 추가 동작을 정의한다.

## Requirements

### Requirement: 여러 장 추가 진입
덱 상세 화면은 카드가 있든 없든 "여러 장 한 번에 추가" 동작을 제공해야 한다(SHALL). 누르면 그 덱의 여러 장 추가 화면이 열리고, 뒤로가기를 하면 덱 상세로 돌아간다. 이 화면의 주소로 바로 열어도 같은 화면이 열리며 뒤로가기는 덱 상세로 간다.

#### Scenario: 덱 상세에서 열기
- **WHEN** 덱 상세에서 "여러 장 한 번에 추가"를 누른 뒤 뒤로가기를 누른다
- **THEN** 여러 장 추가 화면이 열렸다가 덱 상세로 돌아온다

### Requirement: 줄 해석 규칙
여러 장 추가 화면은 붙여넣은 글을 줄 단위로 해석해야 한다(SHALL). 빈 줄은 건너뛴다. 줄에 탭이 있으면 첫 탭으로, 없으면 첫 " / "로, 그것도 없으면 첫 "|"로 질문과 정답을 나누고 앞뒤 공백을 지운다. 구분자가 없거나, 질문·정답 중 하나가 비었거나, 500자를 넘으면 그 줄은 오류다. 빈 줄을 뺀 줄이 200줄을 넘으면 추가할 수 없다.

#### Scenario: 세 가지 구분자
- **WHEN** "apple / 사과", "banana | 바나나", 탭으로 나눈 "cherry	체리" 세 줄을 붙여넣는다
- **THEN** 질문·정답이 apple·사과, banana·바나나, cherry·체리인 3장이 추가 예정으로 보인다

#### Scenario: 정답에 구분자가 들어 있음
- **WHEN** "비율 / 3 / 4"를 붙여넣는다
- **THEN** 질문 "비율", 정답 "3 / 4"로 해석된다

#### Scenario: 오류 줄
- **WHEN** "구분자 없는 줄"과 " / 정답만"을 포함해 붙여넣는다
- **THEN** 두 줄이 줄 번호와 이유(구분자 없음, 질문 비어 있음)와 함께 오류로 표시된다

#### Scenario: 줄 수 초과
- **WHEN** 빈 줄을 뺀 201줄을 붙여넣는다
- **THEN** 200줄까지 추가할 수 있다는 안내가 보이고 추가 동작이 비활성화된다

### Requirement: 미리 보기와 추가
여러 장 추가 화면은 입력이 바뀔 때마다 추가될 카드 수와 오류 줄 목록을 보여 주고, 올바른 줄이 1개 이상일 때만 "N장 추가" 동작을 열어야 한다(SHALL). 누르면 올바른 줄만 입력 순서대로 이 덱의 새 카드(신규 카드와 같은 일정)로 만든다. 오류 줄이 없었으면 덱 상세로 돌아가고, 있었으면 입력란에 오류 줄만 남기고 추가한 수를 알려 준다. 같은 입력이 두 번 추가되어서는 안 된다(MUST NOT).

#### Scenario: 모두 올바름
- **WHEN** 올바른 3줄을 붙여넣고 "3장 추가"를 누른다
- **THEN** 덱 상세로 돌아오고 카드가 3장 늘어 있으며, 새 카드는 오늘 복습 대상이다

#### Scenario: 오류 줄이 섞임
- **WHEN** 올바른 2줄과 오류 1줄을 붙여넣고 "2장 추가"를 누른다
- **THEN** 카드 2장이 추가되고, 입력란에는 오류 줄만 남으며 2장을 추가했다는 안내가 보인다

#### Scenario: 연타
- **WHEN** "3장 추가"를 빠르게 두 번 누른다
- **THEN** 카드는 3장만 추가된다
