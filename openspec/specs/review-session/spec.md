# review-session Specification

## Purpose

한 번의 학습 세션이 진행되는 규칙을 정의한다. 세션 날짜 고정, 뒤집기와 판정의 순서, 일정에 반영하는 판정의 범위, 기억 못 한 카드의 재출제, 세션 요약을 다룬다.

## Requirements

### Requirement: 세션 날짜 고정
세션은 시작한 날의 기기 로컬 날짜를 세션 날짜로 고정하고, 세션 중 모든 판정을 그 날짜로 반영해야 한다(SHALL). 세션 도중 자정이 지나도 세션 날짜는 바뀌지 않는다.

#### Scenario: 자정 경과 (S-09)
- **WHEN** 2026-10-26 23:59에 시작한 세션에서 2026-10-27 00:01에 카드를 판정한다
- **THEN** 판정은 2026-10-26 날짜로 반영된다

### Requirement: 뒤집기 후 판정
세션은 카드의 질문을 먼저 보여 주고, 정답을 확인(뒤집기)하기 전에는 판정을 받아서는 안 된다(MUST NOT).

#### Scenario: 뒤집기 전 판정
- **WHEN** 질문만 보이는 상태에서 판정을 시도한다
- **THEN** 판정이 반영되지 않고 같은 카드의 질문 상태가 유지된다

### Requirement: 첫 판정만 반영과 재출제
세션은 카드마다 세션에서의 첫 판정만 일정에 반영해야 한다(SHALL). 첫 판정이 기억 못 함인 카드는 큐를 모두 돈 뒤 한 번 더 보여 주되, 그 재출제 판정은 일정과 판정 기록에 반영해서는 안 된다(MUST NOT).

#### Scenario: 기억 못 한 카드 재출제
- **WHEN** 카드 A·B·C 세션에서 B를 기억 못 함, A·C를 기억함으로 판정한다
- **THEN** C 다음에 B가 한 번 더 나오고, B의 두 번째 판정은 일정과 기록에 반영되지 않는다

#### Scenario: 재출제는 한 번
- **WHEN** 재출제된 B를 다시 기억 못 함으로 판정한다
- **THEN** B는 더 나오지 않고 세션이 끝난다

### Requirement: 진행 표시
세션은 현재 몇 번째 카드인지와 전체 카드 수(재출제 포함)를 알려야 한다(SHALL).

#### Scenario: 진행 수
- **WHEN** 카드 3장 세션에서 두 번째 카드를 보고 있다
- **THEN** 진행은 2/3이다

### Requirement: 세션 요약
세션이 끝나면 시스템은 일정에 반영된 판정 수(완료 수), 그중 기억함 수, 세션 날짜 다음 날에 복습 예정인 카드 수(전체 덱 기준)를 알려야 한다(SHALL).

#### Scenario: 요약
- **WHEN** 카드 3장 세션에서 2장 기억함, 1장 기억 못 함(재출제 기억함)으로 끝난다
- **THEN** 완료 3, 기억함 2이고, 내일 예정 수에는 기억 못 한 카드와 stage 1로 오른 카드가 포함된다
