# sample-deck Specification

## Purpose
카드가 하나도 없는 사용자가 직접 카드를 만들기 전에 예시 카드로 학습 흐름을 바로 체험할 수 있게 하는 예시 덱 만들기 동작을 정의한다.

## Requirements

### Requirement: 예시 덱 만들기
카드가 하나도 없을 때 홈의 첫 사용 안내는 "예시 카드로 둘러보기" 보조 동작을 보여 주어야 한다(SHALL). 누르면 "예시" 과목과 그 아래 영단어 덱(질문·정답이 있는 카드 10장, 모두 오늘 복습 대상)을 만들고, 홈에 오늘 복습 10장이 보이게 한다. 안내에는 예시 과목을 과목·덱 관리에서 지울 수 있다는 점을 함께 적는다. 동작은 한 번만 실행되어야 한다(MUST).

#### Scenario: 예시 덱 생성
- **WHEN** 카드가 없는 홈에서 "예시 카드로 둘러보기"를 누른다
- **THEN** 과목 목록에 "예시" 과목과 카드 10장짜리 덱이 생기고, 홈에 오늘 복습 10장과 학습 시작 버튼이 보인다

#### Scenario: 카드가 있으면 숨김
- **WHEN** 카드가 1장 이상 있는 상태에서 홈을 연다
- **THEN** "예시 카드로 둘러보기" 동작이 없다

#### Scenario: 연타
- **WHEN** "예시 카드로 둘러보기"를 빠르게 두 번 누른다
- **THEN** "예시" 과목은 하나만 생긴다
