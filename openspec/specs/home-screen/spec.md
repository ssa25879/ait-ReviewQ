# home-screen Specification

## Purpose
앱을 열면 처음 보이는 홈 화면이 오늘 복습할 분량을 어떻게 요약하고, 사용자를 학습·과목 관리로 어떻게 안내하는지 정의한다.

## Requirements

### Requirement: 오늘 복습 요약
홈 화면은 기기 로컬 오늘을 기준으로 전체 덱의 오늘 복습 수(하루 상한 때문에 빠진 카드 포함)와 그중 연체 수(다음 복습일이 오늘보다 이전인 카드 수)를 보여 주어야 한다(SHALL).

#### Scenario: 오늘 예정과 연체
- **WHEN** 다음 복습일이 오늘인 카드 2장과 3일 전인 카드 1장, 내일인 카드 4장이 있다
- **THEN** 홈에 오늘 복습 3장, 연체 1장이 보인다

#### Scenario: 연체 없음
- **WHEN** 오늘 복습할 카드가 모두 다음 복습일이 오늘이다
- **THEN** 연체 수는 보이지 않거나 0으로 보인다

### Requirement: 학습 시작
오늘 복습할 카드가 1장 이상이면 홈 화면은 전체 덱 학습 세션을 시작하는 "학습 시작" 동작만 하단 고정 버튼으로 보여 주어야 한다(SHALL). 과목 관리는 바로가기 타일에서 연다. 세션의 전체 카드 수(재출제 제외)는 홈에 표시된 오늘 복습 수에서 상한 때문에 빠진 수를 뺀 값과 같아야 한다(MUST).

#### Scenario: 홈에서 학습 시작
- **WHEN** 오늘 복습 3장인 홈에서 학습 시작을 누른다
- **THEN** 전체 덱 학습 세션 화면이 열리고 진행은 1/3이다

### Requirement: 과목별 요약
홈 화면은 과목마다 그 과목 덱들의 오늘 복습 수("오늘 N장")와 전체 카드 수("전체 M장")를 함께 보여 주고, 과목·덱 목록 화면으로 가는 동작을 제공해야 한다(SHALL). 오늘 복습 수가 0이어도 전체 카드 수로 카드가 있다는 것을 알 수 있어야 한다.

#### Scenario: 과목별 오늘 복습 수
- **WHEN** 과목 "영어"에 카드 5장 중 오늘 복습 2장, 과목 "수학"에 카드 3장 중 오늘 복습 0장이 있다
- **THEN** 홈에 "영어 오늘 2장 · 전체 5장", "수학 오늘 0장 · 전체 3장"이 보인다

#### Scenario: 과목·덱 관리 진입
- **WHEN** 홈에서 과목 행을 누른다
- **THEN** 과목·덱 목록 화면이 열리고, 뒤로가기를 누르면 홈으로 돌아온다

### Requirement: 홈 빈 상태
카드가 하나도 없으면 홈 화면은 과목·단원을 만들고 카드를 추가하라는 첫 사용 안내와 "과목·단원 만들기" 하단 버튼, 예시 카드로 둘러보는 보조 동작을 보여 주어야 한다(SHALL). 카드는 있지만 오늘 복습할 카드가 없으면 오늘 복습할 카드가 없다는 안내를 보여 주고 학습 시작 동작을 보여서는 안 된다(MUST NOT). 진입하자마자 바텀시트나 대화상자를 띄워서는 안 된다(MUST NOT).

#### Scenario: 첫 사용
- **WHEN** 가이드를 본 기록이 있고 카드가 하나도 없는 상태에서 앱을 연다
- **THEN** 홈에 첫 사용 안내와 "과목·단원 만들기" 버튼, "예시 카드로 둘러보기"가 보이고 대화상자는 열리지 않는다

#### Scenario: 오늘 복습 없음
- **WHEN** 모든 카드의 다음 복습일이 내일 이후다
- **THEN** 홈에 오늘 복습할 카드가 없다는 안내가 보이고 학습 시작 버튼은 없다

### Requirement: 하루 상한 초과 안내
오늘 복습 대상이 하루 상한을 넘으면 홈 화면은 상한까지만 학습하고 나머지 수는 다음 날 이어서 나온다는 안내를 보여 주어야 한다(SHALL).

#### Scenario: 130장 대상
- **WHEN** 오늘 복습 대상이 130장이다
- **THEN** 홈에 오늘 복습 130장과 함께 나머지 30장은 내일 이어서 나온다는 안내가 보인다

### Requirement: 시계 되돌림 경고 표시
기기 날짜가 마지막으로 앱을 연 날보다 이전으로 판정되면 홈 화면은 기기 날짜를 확인하라는 경고를 화면 안의 안내로 보여 주어야 한다(SHALL). 경고 때문에 학습이나 편집을 막아서는 안 된다(MUST NOT).

#### Scenario: 날짜를 되돌린 기기
- **WHEN** 마지막으로 앱을 연 날이 2026-10-26이고 기기 날짜가 2026-10-20인 상태에서 앱을 연다
- **THEN** 홈에 기기 날짜를 확인하라는 경고가 보이고, 2026-10-20 기준 오늘 복습 수와 학습 시작 동작은 그대로 보인다

### Requirement: 홈 머리말
홈 화면은 맨 위에 앱 이름("복습큐")과 오늘 날짜(예: 10월 27일 (월))를 보여 주어야 한다(SHALL). 사용자가 지금 화면이 앱의 첫 화면임을 알 수 있게 하기 위해서다. 상단 내비게이션 바는 직접 그리지 않는다.

#### Scenario: 머리말 표시
- **WHEN** 홈을 연다
- **THEN** 화면 맨 위에 "복습큐"와 오늘 날짜가 보인다

### Requirement: 홈 바로가기 타일
홈 화면은 오늘 복습 요약 아래에 통계·과목 관리·설정 바로가기 타일 3칸(아이콘과 이름)을 한 줄로 보여 주어야 한다(SHALL). 각 타일은 44px 이상 누를 수 있고, 누르면 통계·과목·단원 목록·설정 화면으로 이동하며, 뒤로가기를 하면 홈으로 돌아온다. 카드가 없는 첫 사용 상태에서도 보인다.

#### Scenario: 타일로 이동
- **WHEN** 홈에서 통계·과목 관리·설정 타일을 차례로 눌렀다가 각각 뒤로가기를 누른다
- **THEN** 통계·과목·단원·설정 화면이 열렸다가 매번 홈으로 돌아온다
